# 🍌 Banana Bot Beatdown 🍌

**Release Date:** 14 December 2025  
**Developer:** Big Banana Incorporated  
**Website:** https://einarfriffi.itch.io/bananabotbeatdown

## 🎮 Controls

### Controller
- **Left Stick** — Move
- **Right Stick** — Aim
- **A / X** — Jump
- **Right Trigger** — Shoot
- **Start** — Pause
- **B / O** — Go Back

### Keyboard
- **WASD / Arrow Keys** — Move
- **Arrow Keys** — Aim & Shoot
- **Space** — Jump
- **Escape** — Pause
